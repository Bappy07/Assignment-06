# Fitness-web
Fitness-wev is a simple workout planning and tracking website. Users can browse workouts, check workout details, create a daily plan, and save workouts for later.
## Technologies
! Next.js
! React
! TypeScript
! Tailwind CSS
! DaisyUI
! Sonner
! REST API
## Key Features
1. Browse different workouts
2. View workout details and instructions
3. Add workouts to today's plan
4. Save workouts for later
5. Sort workouts by duration, calories, or rating
